# Proyecto Investigacion IoT Seguridad Ciudadana Con Enfasis En Genero

## Descripción del proyecto

Este proyecto integra técnicas de machine learning y métodos de optimización de redes para simular y analizar casos de violencia urbana, considerando la localización óptima de dispositivos LoRaWAN en la ciudad de Santiago de Cali.

El objetivo es apoyar la toma de decisiones en planificación urbana y seguridad ciudadana mediante modelos espaciales y algoritmos de optimización multiobjetivo.
